# Project Purpose

Retirement hobby project to develop a virtual "insilico-organism" that behaves in accord with the observations of behavior analysis as documented in [Skinner's work](https://www.bfskinner.org/bookstore/), [JEAB](https://onlinelibrary.wiley.com/journal/19383711), JABA, JVB, JOBM, etc.

Such a virtual organism could ultimately be used to test "what if" behavioral scenarios as a cheap, fast, convenient way to test out behavior analytic ideas, procedures, etc. It could also be used in teaching and training.

Just getting back to this project after a seven year hiatus. I expect progress will be glacial: I'm old.

### LLM Usage

I find the current crop of "AI" tools very useful, but very error prone. AI chat tools are very much like interacting with a very junior staffer who believes they know everything about everything (or like interacting with me on my bad days). It is important to remember that LLMs are [intraverbal](https://alldayaba.org/blog/f/understanding-verbal-operants-in-aba-verbal-behavior-definitions) machines. Some LLMs have scaffolding around them that attempts to ground them in external reality, but some of them (or depending on configuration) simply generate stream of consciousness detached from reality ("hallucinations").

I assume an error rate of 10-30% for each query, depending upon domain. LLMs are generally  suited for coding tasks: here I find that the code it generates is about 90% useful. For general behavior analysis information that relies upon older books and articles, LLMs also seem to generate something useful about 90% of the time. It does start falling off on more philosophical topics such as comparisons of radical behaviorism and interbehaviorism, probably because of highly opinionated and biased materials on the Internet. But my philosophy is to avoid philosophy.

Thus, with regard to LLMs I do:
- Use LLMs
- Primarily use them as search facilities that generate pretty good summaries and often references that are actually relevant.
- Occassionally use them as copy editors to help me filter instances of Appalachian dialect in my writing, as well as catching stupid grammar errors, etc. Should probably do this more often than I actually do.
- Sometimes quote LLM output, but ***ALWAYS*** tag the text with a warning that it was generated by an LLM, and requires fact checking. These LLM quotes will generally be tagged as "TODO" items.

So: take everything I say with a grain of salt, but take my LLM quotes with a stiff drink.
